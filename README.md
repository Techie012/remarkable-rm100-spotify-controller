# remarkable-rm100-spotify-controller
100% VIBE CODED!!!! : Native Spotify display for the original reMarkable (RM100 / reMarkable 1), featuring album art, track details, and touch controls for playback, volume, shuffle, and repeat. Use queue, choose a Spotify Connect device, save tracks, check battery and Wi-Fi, rotate, and auto launch on boot. Requires SSH access and Spotify Dev app.
